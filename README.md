# NFTMarketplace

Projeto inicial de marketplace NFT com React, TypeScript e Vite.

## Começar

```bash
pnpm install
pnpm dev
```

Para validar a versão de produção:

```bash
pnpm build
```

## Publicar na Vercel

1. Importe este repositório em [vercel.com/new](https://vercel.com/new).
2. Mantenha o gerenciador `pnpm` detectado pela Vercel e confirme as configurações do projeto:
   - Comando de build: `pnpm build`
   - Diretório de saída: `dist`
3. Clique em **Deploy**. O arquivo `vercel.json` configura esses valores e o fallback para rotas da aplicação.

Novos pushes na branch conectada geram implantações automaticamente.
